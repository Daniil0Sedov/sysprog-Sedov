# Заказ 07 — передача файлов по локальной сети
`payloads/` — набор исходных файлов. Напишите сами TCP-сервер и TCP-клиент,
которые передают файл и сохраняют его на принимающей стороне.

Запустите клиент и сервер на одной машине через 127.0.0.1, затем на разных
компьютерах в разрешённой локальной сети. Никаких внешних хостов не требуется.

Проверки: 1) маленький текст; 2) кириллическое имя; 3) двоичный файл;
4) большой файл; 5) остановка клиента на середине передачи;
6) повторная передача под тем же именем. Не считайте один recv полным файлом.

Проверка целостности: `python verify_files.py payloads received`.
Скрипт сравнит файлы по SHA-256, и отметит недостающие/изменённые.
В исходном каталоге ничего не меняйте.

## Запуск решения

Нужен Python 3. В первом терминале из этой папки запустите сервер:

```text
python server.py
```

Во втором терминале отправьте файл (команда подходит для Windows):

```text
python client.py "payloads\hello.txt"
python client.py "payloads\заказ № 407.txt"
python client.py "payloads\binary_512kb.bin"
python client.py "payloads\binary_3mb.bin"
python client.py "payloads\empty_file.txt"
python verify_files.py payloads received
```

Для двух компьютеров на принимающем компьютере используйте `python server.py --host 0.0.0.0`, а на отправляющем — `python client.py "payloads\hello.txt" --host IP_ПРИНИМАЮЩЕГО`. Оба компьютера должны находиться в разрешённой локальной сети; при необходимости разрешите Python входящие подключения в брандмауэре для частной сети. Папка `received` создаётся на стороне сервера. Сервер останавливается клавишами Ctrl+C.

Клиент передаёт имя и размер, затем данные частями. Сервер сохраняет их во временный файл и заменяет конечный файл только после полного приёма. Если передача прервалась, временный файл удаляется, а предыдущая версия сохраняется. При повторной успешной отправке файл с тем же именем заменяется.
